# أدوات قراءة الشروح من المكتبة الشاملة

أدوات صغيرة استُعملت لإعداد `data/sharh_review.md`. تحفظ الصفحات في `.cache/` (مُستثنى من git).

- `python3 sh.py BOOK PAGE_ID [N]` — نص الصفحة مع الجزء والصفحة المطبوعة.
- `python3 find.py BOOK N...` — موضع الحديث برقمه (1673 فتح الباري، 1711 النووي، 21662 تحفة الأحوذي).
- `python3 grab.py BOOK PAGE_ID N "عبارة" [طول]` — مقتطف يبدأ من العبارة.
- `python3 crumb.py BOOK PAGE_ID...` — الكتاب والباب.

عون المعبود (5760) بلا أرقام أحاديث قابلة للبحث الثنائي؛ يُبحث فيه بنص الباب.
