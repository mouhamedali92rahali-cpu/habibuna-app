# حبيبنا

مواقف صغيرة .. تكشف لك عظمة شخصيته ﷺ

بطاقات قصيرة موثّقة من السنة الصحيحة، تتتابع في الصفحة وتصل كإشعارات. تطبيق ويب تقدّمي (PWA) بالعربية، مبني بـ Vite + React + TypeScript.

## التشغيل محليًّا

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

- البطاقات في `public/cards.json` وتُحمَّل وقت التشغيل، فيمكن تحديثها دون إعادة بناء الواجهة.
- ملفات التحرير والمراجعة في `data/`.
- دليل المشروع وقواعد التحرير في `CLAUDE.md`.
